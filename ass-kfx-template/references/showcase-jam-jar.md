# 华丽范例：果酱罐

这是目标水准。starter_build.py 给的是能跑的起点，这一份展示一首歌做到「用户满意」时是什么样子。
开始设计前读一遍，设计方案要朝这个水准去想，而不是停在给文字加几个飘动的图形。

代码：assets/examples/jam_jar/（build_jam_jar.py 是生成器，art.py 是罐子、格子布、蝴蝶结、草莓的图形，
glyph_build.py 是补字，label_text.py 把「いちご」三个字转成罐子标签上的绘图）。
它依赖原歌曲的样式、字体和补字编号，不能直接用在别的歌上，拿来读和借鉴。

## 背景

《与你相恋到生命尽头》第 12 集插入曲，画面是两个主角一起做草莓果酱：吃草莓、煮草莓、一起搅拌，
最后镜头停在一罐做好的果酱上，暖光。米米系着红白格子围裙。歌词反复说这些小事终究会被忘记。
共 14 句，日文在上、中文在下。

## 核心想法

**果酱就是把草莓存起来；歌词说小事会忘，那就让整首歌把它们一句句存进罐子里。**

一个设计点子同时回应了歌词的主题（记住、保存）和画面的内容（做果酱），这是它显得有分量的原因。
先找到这样一个把歌词和画面连起来的点子，再决定具体效果。

## 效果时间线

| 时刻 | 发生什么 | 对应什么 |
|---|---|---|
| 第一句前 0.7 秒 | 左上角空罐子弹出来 | 开始做果酱 |
| 每一句句首 | 一颗草莓和第一个日文字一起加速下落 | 往锅里放草莓 |
| 句首后 200ms，同一帧 | 草莓碰到果酱液面、第一个日文字落地、中文从下方弹出；罐子颠一下，溅起果酱点，液面上涨一截，罐肩闪一下 | 同步的「落地」是整个效果的节拍 |
| 句中 | 玻璃每 6 到 7 秒有反光扫过，果酱里偶尔冒气泡 | 让静止的罐子活着 |
| 14 句唱完 | 罐子差不多满了 | 整首歌累积的结果 |
| 切到果酱罐镜头那一刻 | 盖上红白格子布、系蝴蝶结、一圈闪光、暖光 | 围裙的红白格；卡在切镜点 |
| 下一个镜头前 | 罐子淡出 | 收尾 |

文字本身：日文小字奶油色、树莓色描边，从上方落下压扁回弹；中文大字贴纸式（粉描边加深莓色实心投影），
出现时草莓粉褪成奶油色；退场沿很平的弧线上浮淡出，飘出白色草莓花；最后一句有金色光波扫过。

## 为什么华丽

1. **跨句的累积**：罐子从空到满贯穿整首歌，观众会期待下一颗草莓。只在单句里做效果的模板没有这种连续感。
2. **一个清楚的节拍**：每句都有一个同一帧对齐的落地瞬间，多个元素（草莓、字、中文、罐子、液面、飞溅）在这一刻一起反应。
3. **细节层次**：罐子由 20 多层绘图组成（玻璃、果酱、果块、光点、液面、描边、高光、标签、瓶口、格子布三色、缎带、结），每层有自己的颜色和透明度。
4. **从画面取材**：格子布用围裙的红白格，标签写「いちご」，暖光对应最后一个镜头的光线。
5. **高潮卡在切镜点**：封口时刻 = 最后一句开始后 3.2 秒 = 切到果酱罐镜头的那一帧。
6. **一直有小动静**：反光、气泡、闪光让画面在歌词停留时也不死板，但都很小，不抢文字。

## 代码里怎么组织（对照 templater-cookbook.md）

- **跨句状态**：每句日文的 setupLine() 把句首、句尾、落地时刻存进全局表 SONG（cookbook 第 8 节）。
- **全局罐子行**：单独样式 12IN罐v2 的一句注释行，放在所有歌词之后。它的模板 `jarAll()` 一次读完 SONG，
  用 `retime("set", 绝对开始, 绝对结束)` 和 `relayer()` 生成整首歌的罐子、每句的草莓和飞溅、气泡、反光、封口。
- **液面**：果酱各层用矩形 \clip 限制在液面以下，每句落地时 `\t(落地, 落地+550, 0.6, \clip(新液面))` 涨上去（第 7 节）。
- **罐子颠一下**：罐子所有层共用同一串 \t 缩放，在每个落地时刻做一次 103.5% × 96.5% 的压扁回弹。
- **对齐**：罐子所有部件共用一个包围盒 `m -8 -14 m 80 96`，草莓三层共用 `m 0 0 m 52 60`（第 6 节）。
- **加速下落**：文字和草莓都用绕远处 \org 旋转做位移，加速参数 2 模拟重力（第 5 节）。
- **参数表**：C（颜色）和 P（时间位置）集中在第一行 code once，带中文注释，封口时间 P.sealDelay 可以直接调。

## 这个版本是怎么改出来的

1. v1：草莓落下压扁变成字，字上浮退场飞出草莓花，最后一句金色光波。用户：「效果还是不够漂亮，不用拘泥原本的样式，好看优先，旧版不要覆盖，新做一个 v2，字体不换。」
2. v2：加入果酱罐的累积设计。用户：「草莓落进罐子和字幕出现不太同步」「日语字号小、中文字号大」。
3. v2 修正：原因是草莓提前 80ms、第一个字晚 240ms，且草莓匀速下落没有落地瞬间。改成同一帧加速落地，
   中文在这一刻弹出；字号改为日文 40、中文 58，贴纸样式移到中文。检查中还发现罐口画成不透明白盖，
   草莓看起来穿过盖子，改成半透明玻璃瓶口。

## 用到别的歌上

不要照搬罐子。照搬的是思路：

- 找一个同时回应歌词主题和画面内容的「容器」或「进度」：
  - 写信的歌：信纸一句句写满，最后折起来装进信封。
  - 看星星的歌：每句点亮一颗星，最后连成星座。
  - 旅行的歌：每句在地图上走一段路，最后到达目的地。
  - 做蛋糕的歌：每句放一层奶油或一颗水果，最后插上蜡烛。
- 定一个每句都有的同步节拍，让多个元素在同一帧反应。
- 把高潮卡在画面切镜点。
- 从画面里拿颜色和图案。

这种设计工作量大，也不一定每首歌都适合。歌曲很短、画面很杂或用户只要简洁效果时，用 starter 加配方就够了。
方案先用几句话告诉用户，让用户知道你打算做多大的效果。

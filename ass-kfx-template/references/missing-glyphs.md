# 补缺字

特效字幕常用的艺术字体（例如方正达利体）字库不全，日文里的「気」「別」这类字经常缺。缺字时渲染器会换成别的字体，或者显示方框，风格明显不一致。

## 流程

1. **查**：`python scripts/glyph_check.py 歌词.ass`，开工第一步就做。
2. **提方案，让用户选**（用户倾向尽量不换字）：
   - 拼字：用本字体已有的笔画和部件拼出缺的字。风格最统一，花时间。
   - 借字体：从风格接近的字体取这个字（glyph2ass 直接取）。快，但笔画风格有差异。
   - 换字：例如「気」改成「氣」，「別」改成「别」。只在用户同意时做。
3. **做字形**，存进补字表 JSON。
4. **验证**，再生成模板（`starter_build.py --glyph-json 补字.json`）。模板会自动把缺的字换成绘图，并修正后面文字的位置。

## 拼字

先看两个来源字的轮廓编号：
```
python scripts/glyph2ass.py "字体名" 别 --list --preview 别.png
python scripts/glyph2ass.py "字体名" 氣 --list --preview 氣.png
```
--preview 画出每个轮廓并标上编号。然后写一个小脚本组合：

```python
import sys; sys.path.insert(0, "scripts")
from fontfind import open_font
from glyph2ass import load, save_json

f = open_font("方正达利体简繁 Heavy")
qi = load(f, "氣")          # 取「气」字框
qu = load(f, "区")          # 取「区」里的叉
frame = qi.pick([4, 5, 7])  # 编号来自 --list / --preview
x = qu.pick([0]).fit((55, -72, 665, 368))  # 缩放到原来「米」所在的框（字体单位，y 向上）
x = x.embolden(8)           # 缩小后笔画变细，向外扩几个单位补回粗细，和框架横画比对
save_json("补字.json", "気", frame + x)
```

常见的拼法：
- 「別」：字体里只有简体「别」时，「别」的「口」和「力」常被画成一个轮廓。日文「別」的撇不出头、「口」独立，需要把连接段切开。按点的序号切：`load` 返回的轮廓是 [(op, [点...]), ...] 列表，可以直接切片重组。
- 「気」：用「氣」的「气」框（这个框本来就为装内部件设计，横折比单独的「气」高）加「区」或「乂」形的叉。
- 其他日文新字体：先找繁体或简体里结构相同的部件，再调整位置大小。

判断拼得好不好：放大预览看笔画粗细是否和旁边的字一致，转角圆度是否一致。

## 验证

`glyph2ass.py 字体 字 --size 字号 --verify` 对**字体里已有的字**比较文字渲染和绘图渲染。用它先验证流程本身（包围盒一致、墨迹差几个百分点以内即正常，抗锯齿造成的差异会随字号正负变化）。

拼出来的字没有「真字」可比。做法：把它和相邻的字一起放进一句测试字幕，用 render.py 放大 4 倍截图，看大小、基线、粗细是否一致。

## 注意

- 字体自身字重高于样式请求的字重时（例如字体是 Heavy 900，样式 Bold 700），libass 不做伪粗体，绘图也不需要加粗。字体只有常规体而样式要求粗体时，libass 会做伪粗体，绘图要用 `\bord` 或 embolden 补一点。
- 补字是绘图，和多层图形一样只保证 libass。
- 补字表是按某个字体的轮廓做的，换字体要重做。
- 交付说明里写明补了哪些字、用什么方法。
